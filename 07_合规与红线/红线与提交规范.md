# 07 合规与红线（违规=取消资格）

> 依据讲义第 13 章。**每年有 5%-10% 的队伍因违规被取消资格——不是模型不行，是规矩没搞清。**
> 查重、引用、格式、提交，每一条都可能是雷。

## 一、查重红线（碰了就淘汰，讲义表 23）

| 查重类型 | 红线标准 | 检测方式 |
|---|---|---|
| 论文正文查重 | 全文重复率 > 25% | 系统自动比对（知网/万方） |
| 代码查重 | 代码相似度 > 50% | MOSS 等代码查重系统 |
| 附录查重 | 与知网/已发表论文重复 | 和正文一起查 |
| 跨队查重 | 两队论文高度相似 | 全省论文交叉比对 |

**注意**：学校图书馆一般有查重系统，**赛前自查一次**；公式推导部分最容易重复（大家都抄教材）——用自己的话改写；引言/背景必须自己写。

## 二、引用规范（讲义 13.2）

- 原则：**凡是别人的观点、数据、公式、图表，必须标注出处。不标 = 抄袭。**
- 不用引：数学常识、你自己推导的公式、自己画的数据图、自己写的代码。
- 格式统一 GB/T 7714（见 `03_论文写作_LaTeX/参考文献_GB7714.md`）。

## 三、代码查重（最容易忽略的雷区，讲义 13.3）

**算违规**：直接复制 GitHub 完整项目代码；与另一队代码高度相似（改变量名但逻辑一致）；AI 生成代码不加修改直接用。
**不算违规**：调用公开库（sklearn/numpy）；参考思路但自己重写；公共代码模板（读数据、画图模板）。

**安全做法**：
1. 代码自己写/自己改——不直接复制粘贴；
2. 变量名用自己命名习惯；
3. 代码结构有自己的逻辑（别和网上教程一个模子）；
4. 附录附核心代码即可，不必全附。

## 四、格式违规（不起眼但扣分，讲义表 24）

| 违规项 | 正确做法 |
|---|---|
| 论文出现学校/队员名 | **绝对禁止** |
| 超页数 | 正文不超过 20 页（含附录看具体要求） |
| 页边距故意缩小 | 按规范 2.5cm |
| 字体不统一 | 正文/标题/公式统一 |
| 图表无编号 | 每图每表必须有编号+标题 |
| PDF 不清晰 | 矢量图或高分辨率 PNG |

## 五、提交环节（最后一公里翻车，讲义 13.5）

1. **提前 1 小时提交**——最后半小时网站必崩，每年大量队伍超时 0 分。
2. 确认文件格式：**PDF**（不是 Word/图片/压缩包），大小不超标。
3. 确认文件完整：下载自己提交的文件，打开确认能正常显示。
4. **MD5 校验**：提交前记录 MD5，提交后核对。
5. 提交失败：立刻截图 + 联系组委会应急通道。
6. 别等到最后：**17:00 就能交就交，别赌 19:50**。

## 六、违规后果速查（讲义表 25）

| 违规行为 | 后果 |
|---|---|
| 查重率 > 25% | 取消评奖资格 |
| 代码查重 > 50% | 取消评奖资格 |
| 论文出现学校/姓名 | 取消评奖资格（部分省份） |
| 未按时提交 | 0 分 |
| 提交格式错误（非 PDF） | 0 分 |
| 抄袭他人论文 | 取消资格 + 通报学校 |
| 代替他人参赛 | 取消资格 + 处分 |
