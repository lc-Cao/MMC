# 提交前总检查清单（提交日 16:00 起逐项打勾，留 1 小时 buffer）

> 三份清单合一：论文质量、格式合规、提交动作。任何一项没过就立刻处理，别带病提交。

## A. 论文内容（三人分工各读一遍）
- [ ] 每个小问都有"方法 + 结果数值 + 图表"，无遗漏无空节
- [ ] 灵敏度/误差分析/模型对比已在"模型检验"章（缺=降档）
- [ ] 摘要与正文完全一致：方法名都提到、**每个数字都能在正文找到出处**
- [ ] 摘要五段式齐全、800-1200 字、无禁忌词（我们/大概/随着科技发展）
- [ ] 关键词 5-6 个，覆盖"模型+方法+领域"
- [ ] 模型假设 ≤ 8 条、每条有理由；符号表列全所用符号
- [ ] 图表编号连续（图1..n/表1..n），每个图在正文有"如图X所示"对应

## B. 格式合规（讲义 9.9 / 13.4）
- [ ] 全文无学校名、队名、人名
- [ ] 页数符合要求（正文 ≤20 页，含附录按官方要求）
- [ ] 页面 A4、边距 2.5cm；字体统一；公式非截图
- [ ] 参考文献 GB/T 7714，文中引用与文末一一对应
- [ ] 重复率自查 < 25%（学校查重系统）；AI 痕迹自查（AI 内容占比低）
- [ ] 代码自查：非整段复制开源/AI；逻辑与命名有自己风格
- [ ] 导出 PDF 后**逐页翻看**：无乱码、无空白页、图不糊、公式完整

## C. 提交动作（19:00 前，绝不拖到 20:00）
- [ ] 确认官方要求：提交 PDF + 附件清单（哪些要交、命名规则）
- [ ] 生成最终文件（建议命名含队号，如 `2026xxxx队_论文.pdf`）
- [ ] 本地记录 MD5：`certutil -hashfile "论文.pdf" MD5`（Windows）
- [ ] 登录官网提交 → 上传 PDF（必要时按官方要求附代码/支撑材料）
- [ ] **下载自己刚提交的文件**，打开确认完整、MD5 一致
- [ ] 截图提交成功页面留存（万一有争议有证据）
- [ ] 云端/邮箱再备份一份最终 PDF（双保险）

## D. 收尾
