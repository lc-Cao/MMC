# 01 赛制与规则

内容整理自讲义第 1 章《入门：全国大学生数学建模竞赛（CUMCM）》。

## 1. 比赛速览

- **主办**：中国工业与应用数学学会；始于 1992 年，每年 9 月举行，世界规模最大的数学建模竞赛。
- **形式**：三人一组（不限专业，建议"数学/统计 + 计算机 + 工程/经管"）；本科组与专科组分开评奖。
- **时长**：赛题发布后 74 小时（约三天）内提交 **论文 PDF + 附件**，论文为唯一评审依据（无需答辩，国一除外）。
- **参赛价值**：保研加分（国奖权重最高）；建模+编程+写作三合一能力证明；求职/申请中被广泛认可。

## 2. 题型与选题（讲义表 1）

| 题号 | 倾向 | 典型场景 | 涉及方法 |
|---|---|---|---|
| A | 物理/工程 | 热传导、应力分析、天线设计、CT 成像 | 微分方程、有限元、数值模拟 |
| B | 社会/经济 | 交通优化、资源分配、政策评估、调度 | 优化模型、图论、博弈论 |
| C | 数据/统计 | 分类识别、预测、综合评价、异常检测 | 机器学习、统计建模、数据分析 |
| D | 优化/运筹 | 路径规划、生产调度、库存管理 | 线性/整数规划、启发式算法 |
| E | 综合/交叉 | 环境评估、生态建模、传染病、能源 | 机理 + 数据混合建模 |

**选题策略**
- C 题（数据题）选的人最多（约 40%），门槛低但区分度小，难冲国一；
- A/B 题选的人相对少（各约 20-25%），区分度大，做得好容易冲国奖，但难度高；
- 有物理/工科背景 → 优先 A/B 题；纯数学/统计/计算机 → C 题最稳；跨学科 → B 或 E。

## 3. 出题规律（讲义 1.3）

1. **三年不重复，但有周期**：同领域题目不连续出现，但每 3-4 年类似题型会以新面貌回归。
2. **热点映射**：当年社会/科技热点大概率进入赛题（如 2020 传染病、2022 碳中和、2024 AI/大数据）。
3. **数据题(C)年年有**：2015 起 C 题固定为大数据/统计方向，通常给 Excel/CSV 附件。
4. **每道题 3-4 个小问，递进逻辑**：第 1 问入门验证、第 2-3 问复杂、第 4 问常为改进/灵敏度。
   评分分问计分——前两问做不完不影响后两问。

## 4. 获奖率与评奖机制（讲义表 2）

| 奖项 | 大致比例 | 说明 |
|---|---|---|
| 省一 | 约 8% | 省一中的前 10%-15% 送全国复审 |
| 省二 | 约 15% | 省级直接确定，不送国评 |
| 省三 | 约 20% | 省级直接确定 |
| 成功参赛奖 | 约 57% | 提交有效论文即可获得 |
| 国一 | 约 0.5%-1% | 需答辩（部分年份线上） |
| 国二 | 约 2%-3% | 论文评审，不需答辩 |

> 约 43% 队伍能拿省三及以上；每 100 支队约 3 支拿国奖。

**评审流程**：省组委会初筛（格式违规、全文重复率>25% 或代码重复率>50% 直接排除）→ 2-3 位评委独立打分 → 省一前 10-15% 送全国复审 → 产生国一/国二 → 国一候选答辩。

## 5. 必备工具（讲义表 3）

| 类别 | 工具 | 用途 |
|---|---|---|
| 编程 | Python(NumPy/SciPy/sklearn/statsmodels) | 数据处理、建模求解、机器学习 |
| 编程 | MATLAB（备选） | 数值计算、偏微分方程 |
| 绘图 | Matplotlib / seaborn | 统计图、对比图 |
| 绘图 | draw.io / ProcessOn / TikZ | 流程图、框架图、示意图 |
| 写作 | LaTeX（推荐）| 论文排版 |
| 写作 | Word（备用） | 论文排版（LaTeX 备用方案） |
| 文献 | 知网/万方/Google Scholar | 查背景文献、找建模方案 |
| AI | Claude/GPT/DeepSeek 等 | 赛题分析、代码辅助、绘图辅助（见 05 区） |
| 协作 | Git/坚果云/腾讯文档 | 版本管理、实时协同 |

## 6. 三天 74 小时骨架（详见 `06_赛中作战`）

- D1 晚：读题→22:00 前定题→查文献→第一问建模思路 + 论文框架
- D2：第一问出结果（中午底线）→第二问建模求解→完善前两问（当日底线）
- D3：第三问（最难放上午）→灵敏度/模型检验→论文初稿完整
- D4 上午起：写摘要→反复修改→格式/查重→**19:00 前提交**

## 7. 备赛针对性建议

- 赛前必看最近 3 年 A/B/C 题真题和优秀论文（放 `08_赛题资料库`），至少精读 2 篇。
- 提前积累六大类模型代码模板（本区 `02_模型方法库` 已备好）。
- 提前把论文模板跑通（`03_论文写作_LaTeX`），封面/摘要/章节框架赛前就绪。
- 逐项核对 `赛前速查清单.md`。
