# 国赛备赛与赛中作战工作区（总览）

本文件夹用于 **2026 全国大学生数学建模竞赛（CUMCM）** 的赛前准备与赛中快速取用。
所有分区的内容均依据根目录讲义《2026国赛零基础获奖速成课讲义.pdf》整理，文中会标注"讲义第 X 章"方便回查原件。

> 一句话提醒：国赛 = 三人组队 + 三天 74 小时 + 一篇论文。
> 比的不是谁算得对，是谁的论文让评委觉得"有道理、有水平、做得完"。

## 赛中 3 步快速动线

1. **拿到题目后（第一天 18:00-22:00）**
   - 先按 `06_赛中作战/三天作战时间线.md` 走流程；
   - 每人通读所有题→用 `05_工具与AI/AI提示词库.md` 里的"赛题分析 Prompt"请 AI 做深度分析；
   - 22:00 前定题，查文献，写手开写引言（不等模型）。
2. **定题后**
   - 打开 `02_模型方法库/README.md` 的汇总速查表判断每问属于哪类问题；
   - 进对应子目录：读 README（选型+流程+坑），复制 `.py` 模板到 `09_赛中工作区/数据与代码` 直接改；
   - 每个问都先出"基线结果"再谈优化（生存法则三）。
3. **写作与收尾（全程 + 最后一天）**
   - 第一天晚上就开写：引言/总体分析/框架先用 `03_论文写作_LaTeX` 里的章节骨架；
   - 正文完成后再写摘要（`03_论文写作_LaTeX/摘要写作模板与自检.md`），保证每个数字与正文一致；
   - 提交前走 `07_合规与红线/提交前总检查清单.md`，**提前 1 小时提交并核对 MD5**。

## 三条生存法则（讲义 1.7）

1. **第一天晚上就开始写论文**：建模与写作同步推进，不要等模型全做完再动笔。
2. **不等队友**：建模手给大致方案→编程手用假数据跑通框架→写手先写文字留图表位置，三人并行。
3. **先做出来，再做好**：每个问先给基线结果，全部做完还有时间再回来优化。

## 评分维度（评委按权重排序，讲义 1.4）

1. 模型的合理性（30-40%）  2. 求解的正确性（25-30%）
3. 论文的表达（20-25%）    4. 创新性（10-15%）

评委最看重：为什么选这个模型、数据怎么处理、假设合不合理、**灵敏度分析做了没有**、结论有没有数据支撑。
