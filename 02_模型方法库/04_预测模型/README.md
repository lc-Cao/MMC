# 预测模型（04）

> 讲义第 5 章。套路：预测 = 判断预测类型(时序/非时序) → 选模型 → 拟合 → 评估(MAPE/RMSE) → 预测+区间。
> 核心区分：**数据有时序吗？数据有多少？**

## 什么时候用
- 预测未来值/趋势，有历史数据；
- 关键词：预测、趋势、未来、估计、预报。

## 选型速查（表 10）
| 模型 | 数据量 | 数据类型 | 一句话 |
|---|---|---|---|
| 线性回归 | 不限 | 有特征+标签 | 最简单的基线 |
| ARIMA | ≥30 点 | 纯时间序列 | 时序预测标配 |
| 灰色预测 GM(1,1) | 4-10 点 | 单调序列 | 数据极少时的救命稻草 |
| 神经网络 | 大量 | 任意 | 数据多用不完时选它 |

> 速记：4-10 个点 → GM(1,1)；≥30 个时序点 → ARIMA；有多个特征 → 回归；数据 >10000 → 神经网络。

## 五步解题流程
1. **判断类型**：有时序 → ARIMA/灰色；无时序(多特征→目标) → 回归。
2. **预处理**：时序做平稳性检验(ADF)，不平稳就差分；回归做标准化+划分。
3. **建模**：ARIMA(p,d,q) 用 ACF/PACF 定阶；回归 线性→Ridge/Lasso；灰色仅两个参数(a,b)。
4. **评估**：回归 MSE/MAE/R²；时序 MAPE/RMSE。**必画"预测 vs 真实"图**。
5. **预测+区间**：给点值预测 + 置信区间(90%/95%)——区间是加分项。

## 常见坑（讲义 5.6）
- 数据不够硬上 ARIMA（<30 点用灰色）。
- 灰色预测对**非单调/上下波动**数据失效 → 换回归/ARIMA。
- 不做平稳性检验就用 ARIMA。
- 预测只给点不给区间——"点值+置信区间"才是完整答案。
- 外推须说明假设：灰色预测假设未来按当前趋势发展，有外部冲击要修正。

## 代码说明
- `gm11.py`：灰色预测 GM(1,1)，含级比检验 + MAPE + 拟合/未来 n 期预测（数据少时的主力）。
- `regression_arima.py`：无时序特征预测（线性回归，可换 Ridge/Lasso/随机森林）+ 纯时序 ARIMA 快速上手（含平稳性差分提示）。
