# 优化模型（05）

> 讲义第 6 章。套路：优化 = 确定三要素(决策变量 + 目标 + 约束) → 判断类型 → 选求解方法 → 灵敏度。
> 核心：**能线性化就线性化求精确解，不行再上启发式**。

## 什么时候用
- 题目要求找"最优"——最优路径、最优分配、最优调度；
- 有明确目标 + 明确约束；
- 关键词：最优、最小/最大、调度、分配、路径规划。

## 选型速查（表 12）
| 方法 | 适用条件 | 解质量 | 一句话 |
|---|---|---|---|
| 线性规划 | 目标+约束都线性 | 精确最优 | 能线性化就线性化 |
| 整数规划 | 含整数/0-1 变量 | 精确最优 | 选址、指派问题 |
| 遗传算法 | 非线性/非凸 | 近似最优 | 万能但慢 |
| 粒子群 | 连续优化 | 近似最优 | 收敛比 GA 快 |

## 四步解题流程
1. **三要素建模**：决策变量 + 目标函数 + 约束条件（含隐含约束：非负/整数）。
2. **判断类型**：全线性 → 线性规划；含 0-1/整数 → 整数规划；非线性/非凸 → 启发式（GA/PSO）。
3. **求解**：线性用 scipy/pulp（`lp_solver.py`）；遗传算法用 `ga_template.py`（纯 numpy）。
4. **灵敏度（必做）**：约束右端值 ±20% 重解，看最优值变化；写"影子价格/瓶颈资源"结论。

## 常见坑（讲义 6.6）
- 忘写隐含约束（非负/整数）。
- 线性问题用启发式：能用 LP 就不用 GA——精确>近似且快百倍。
- GA 不收敛：增代数、增种群、降变异率。
- 缺灵敏度分析：优化题必做。

## 代码说明
- `lp_solver.py`：线性/整数规划求解（scipy），含约束右端 ±20% 灵敏度测试；附 pulp 等价写法注释（讲义 Listing 6）。
- `ga_template.py`：30 行级遗传算法（纯 numpy），适合非线性/非凸目标；返回全局近似最优 + 收敛曲线可画图。
