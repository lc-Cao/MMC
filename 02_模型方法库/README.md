# 02 模型方法库（六类全覆盖）

> 内容整理自讲义第 2-7 章。每类一个子目录：README（何时用→选型速查→解题流程→常见坑）+ 可直接运行的 Python 模板。
> 使用顺序：**判断问题类型 → 查汇总速查 → 进子目录复制模板 → 改数据跑基线 → 检验/灵敏度**。

## 一、先判断题目属于哪类问题

| 题目要求 / 关键词 | 问题类型 | 去哪个子目录 |
|---|---|---|
| 打分、排名、优选、综合评价、绩效、选址 | 评价类 | `01_评价模型` |
| 判断"是/否、属于哪类"，有标注（识别/诊断/检测） | 分类 | `02_分类模型` |
| 无标签分组、分群、画像、市场细分 | 聚类 | `03_聚类模型` |
| 预测未来值/趋势，有历史数据 | 预测 | `04_预测模型` |
| 找"最优"（最优路径/分配/调度），有目标+约束 | 优化 | `05_优化模型` |
| 系统有明确物理/生物规律、数据少但有领域知识 | 机理 | `06_机理模型` |

> 一句话模型套路（讲义第 2-7 章总括）：
> - 评价 = 建指标 → 定权重 → 算得分 → 灵敏度
> - 分类 = 预处理 → 选模型 → 训练 → 评估(ROC/F1/混淆矩阵) → 特征重要性
> - 聚类 = 标准化(必做) → 定 K → 聚类 + 画像解释
> - 预测 = 判断类型(时序/非时序) → 选模型 → 拟合 → 评估(MAPE/RMSE) → 预测+区间
> - 优化 = 定三要素(变量/目标/约束) → 判断类型 → 选求解法 → 灵敏度
> - 机理 = 分析规律 → 建方程 → 数值求解 → 参数敏感性

## 二、选型速查（一页浓缩）

### 评价模型（指标可量化+有数据 → TOPSIS+熵权最常用；主观 → AHP；模糊 → 模糊评价）
| 模型 | 权重来源 | 适用条件 | 一句话 |
|---|---|---|---|
| AHP | 专家打分 | 指标 ≤ 9 个 | 两两比较，检验一致性 CR<0.1 |
| TOPSIS | 数据驱动 | 有数据可量化 | 离最优最近、离最劣最远 |
| 熵权法 | 数据离散度 | 数据完整 | 差异越大的指标权重越高 |
| 模糊评价 | 隶属度 | 指标模糊 | 把"好中差"变成数 |

### 分类模型（逻辑回归是基线；类不平衡用 F1/AUC，别用准确率）
| 模型 | 样本量 | 特征数 | 一句话 |
|---|---|---|---|
| 逻辑回归 | 不限 | 少中 | 简单问题首选基线 |
| KNN | 小中 | 少 | 不需训练直接投票 |
| SVM | 小中 | 多 | 小样本高维数据之王 |
| 随机森林 | 不限 | 不限 | 万能模型，自带特征重要性 |

### 聚类模型（距离类算法必须先标准化）
| 模型 | 需预设K | 非球形 | 一句话 |
|---|---|---|---|
| K-means | 是 | 否 | 最简单高效，球形数据就选它 |
| 层次聚类 | 可后选 | 可以 | 树状图直观选 K，适合小数据 |
| DBSCAN | 否 | 是 | 自动发现聚类数，能识别噪声 |

### 预测模型（数据量是第一判据）
| 模型 | 数据量 | 数据类型 | 一句话 |
|---|---|---|---|
| 线性回归 | 不限 | 有特征+标签 | 最简单的基线 |
| ARIMA | ≥30 点 | 纯时间序列 | 时序预测标配 |
| 灰色预测 GM(1,1) | 4-10 点 | 单调序列 | 数据极少时的救命稻草 |
| 神经网络 | 大量 | 任意 | 数据多用不完时选它 |

### 优化模型（能线性化求精确解，不行才上启发式）
| 方法 | 适用条件 | 解质量 | 一句话 |
|---|---|---|---|
| 线性规划 | 目标+约束都线性 | 精确最优 | 能线性化就线性化 |
| 整数规划 | 含整数/0-1 变量 | 精确最优 | 选址、指派问题 |
| 遗传算法 | 非线性/非凸 | 近似最优 | 万能但慢 |
| 粒子群 | 连续优化 | 近似最优 | 收敛比 GA 快 |

### 机理模型（懂规律用方程，懂局部规则用元胞自动机）
| 模型 | 适用场景 | 一句话 |
|---|---|---|
| 微分方程 | 连续变化(温度/传染病/扩散) | 经典严谨，需要推导，数值求解 |
| 差分方程 | 离散时间步(种群代际) | 微分方程的离散版 |
| 元胞自动机 | 局部规则→全局涌现 | 不需方程，定义规则就跑 |

## 三、所有模型的通用纪律（决定分数档）

1. **数据预处理写进论文**：缺失值怎么补、异常值怎么剔、标准化/量纲处理，一句话都不能省。
2. **模型选择必须有依据**：为什么选它不选别的？一句话即可。
3. **灵敏度/误差分析/模型对比 = 国赛硬性要求**，缺了直接降档（讲义第 1.4 节）。
4. **先基线后优化**：每个问先用最简单方法出结果，全做完再回来升级模型。
5. **所有代码设 `random_state`**：保证结果可复现，截图/表格数字一致。
