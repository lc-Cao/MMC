# 机理模型（06）

> 讲义第 7 章。套路：机理模型 = 分析系统规律 → 建立方程 → 数值求解 → 参数敏感性。
> 核心：懂底层规律用微分方程，懂局部规则用元胞自动机。A 类物理/工程题（如热传导）主力在本区。

## 什么时候用
- 系统有明确物理/生物/传播规律；
- 数据少但有领域知识；
- 关键词：动态、传播、扩散、演化、生长、热传导。

## 选型速查（表 14）
| 模型 | 适用场景 | 一句话 |
|---|---|---|
| 微分方程 | 连续变化(传染病、温度) | 经典严谨，需要推导，数值求解 |
| 差分方程 | 离散时间步(种群代际) | 微分方程的离散版 |
| 元胞自动机 | 局部规则→全局涌现 | 不需方程，定义规则就跑 |

## 四步解题流程
1. **分析机理**：找**存量**(数量/温度) 和**流量**(变化率)，画"存量-流量图/系统框图"（论文里必画，评委靠它看懂你）。
2. **建立方程**：微分 `变化率 = 流入 - 流出`（如 SIR：dS/dt=-βSI）；差分 `x(t+1)=f(x(t))`；元胞自动机：邻居+状态转移规则（规则必须与题目背景一致）。
3. **求解**：微分用 `solve_ivp/odeint`；差分递推；元胞自动机迭代。方程复杂不强求解析解，数值解即可。
4. **参数敏感性（必做）**：有数据用最小二乘拟合参数；无数据查文献取合理范围，再扫参数看结果变化（如 β 减半 → 峰值/拐点如何变）。参数来源必须写进论文。

## 常见坑（讲义 7.6）
- 参数无来源：β、γ 等须标"参考 XX 文献"或"由数据拟合"。
- 不画系统框图：机理模型不画存量-流量图 = 评委看不懂。
- 元胞自动机规则想当然：规则须与题目背景一致。
- 方程过于复杂就不求解析解：数值解照样能写进论文。

## 代码说明
- `sir_model.py`：SIR 传染病模板（微分方程 + R0 + 峰值 + β 敏感性扫描）——任何"传播/扩散/演化"类机理题的母版。
- `heat_1d_fdm.py`：一维瞬态热传导有限差分（显式格式）——A 题热/防护/温控场景利器，可改层数/边界条件。
- `ca_forest_fire.py`：元胞自动机森林火灾示例——"局部规则→全局涌现"的最小可跑模板。
