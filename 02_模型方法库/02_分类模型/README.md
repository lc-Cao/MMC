# 分类模型（02）

> 讲义第 3 章。套路：分类 = 数据预处理 → 选模型 → 训练 → 评估(ROC/F1/混淆矩阵) → 特征重要性。
> 选型三看：数据量、特征数、是否需要可解释。

## 什么时候用
- 判断"是/否""属于哪一类"，且有**标注数据**；
- 关键词：识别、诊断、判断、分类、筛选、检测、欺诈、预测是否…

## 选型速查（表 7）
| 模型 | 样本量 | 特征数 | 一句话 |
|---|---|---|---|
| 逻辑回归 | 不限 | 少中 | 首选基线（可解释高） |
| KNN | 小中 | 少 | 不需训练直接投票 |
| SVM | 小中 | 多 | 小样本高维之王 |
| 随机森林 | 不限 | 不限 | 万能模型，自带特征重要性 |

> 规则：先逻辑回归跑基线 → 再试随机森林（或 SVM）对比 → 表格/ROC 说明选型理由。
> 类别不平衡（如欺诈仅 1%）：用 **F1 / AUC**，别用准确率；重点关注**召回率**。

## 五步解题流程
1. **预处理**：缺失值 → 类别编码(One-Hot) → 标准化(SVM/逻辑回归必做) → 划分训练/测试 7:3。
2. **选模型+训练**：先逻辑回归基线，再随机森林/SVM 对比。
3. **评估**：准确率/精确率/召回率/F1 + 混淆矩阵 + ROC/AUC。
4. **特征重要性**：随机森林 `feature_importances_`，选出 Top3 写成业务结论。
5. **模型对比**：表格对比 2-3 个模型性能 → 说明最终选型理由（论文必备表）。

## 常见坑（讲义 3.6）
- 忘标准化：SVM/逻辑回归对尺度敏感。
- 用准确率衡量不平衡数据：应看 F1/AUC。
- 过拟合不自知：训练集 99% / 测试集 70% → 加交叉验证。
- 不设 `random_state`：结果不可复现，论文数字对不上。
