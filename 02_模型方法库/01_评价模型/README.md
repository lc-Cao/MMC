# 评价类模型（01）

> 讲义第 2 章。套路：评价问题 = 建指标 → 定权重 → 算得分 → 灵敏度检验。
> 核心不是算法多复杂，是**指标选得有依据、权重说得清来源**。

## 什么时候用
- 对多个方案/对象打分排名；
- 涉及多个指标且指标间有冲突（价格低 vs 性能高）；
- 关键词：评价、排名、优选、综合评估、绩效、选址。

## 选型速查（表 4）
指标可量化 + 有数据 → **TOPSIS + 熵权法（最常用）**；指标主观 → AHP（指标≤9，需一致性检验 CR<0.1）；指标模糊 → 模糊评价。

## 五步解题流程
1. **建指标体系**：查文献定一级维度 → 拆成可量化二级指标 → 画层次结构图（论文里必画）。
2. **数据预处理**：正向化（成本型取倒数，统一"越大越好"）+ 标准化（min-max 或 z-score）。
3. **定权重**：熵权法（客观）/ AHP（主观）/ 组合法（主观×客观取几何平均，最稳妥）。
4. **算得分**：TOPSIS —— 加权标准化 → 正负理想解距离 → 相对贴近度 C = D⁻/(D⁺+D⁻)。
5. **灵敏度分析（必做）**：每个指标权重 ±10% 重算，看 Top 排名是否变化；稳定才可写"鲁棒"。

## 常见坑（讲义 2.6）
- 忘正向化：成本型当效益型直接算 → 排名完全反过来。
- AHP 不检验一致性：CR>0.1 必须调整判断矩阵。
- 某指标权重≈0：说明该指标无区分度，删掉或说明原因。
- 缺灵敏度分析：评委必查。

## 代码说明
`topsis_entropy.py`：函数接口已拆好（正向化标准化 / 熵权 / TOPSIS / 灵敏度），把数据表换成你的数据即可。
- 默认"成本型=取倒数"正向化（讲义 2.4 所用）；
- 若题目要求区间型/中间型指标，在正向化处按需扩展；
- 若想用 AHP 权重与熵权组合，把 AHP 权重传入 `combine_weight()` 即可。
