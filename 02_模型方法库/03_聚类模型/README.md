# 聚类模型（03）

> 讲义第 4 章。套路：聚类 = 无标签分组。核心三步：**标准化(必做) → 定 K 值 → 聚类 + 画像解释**。
> 选型只看两个问题：你知道要分几类吗？数据分布是球形吗？

## 什么时候用
- 数据**无标签**，需要自动发现分组结构；
- 题目要求：分类(无标注)、分群、分区、用户画像、市场细分；
- 关键词：聚类、分群、区域划分、画像、细分、模式识别。

## 选型速查（表 9）
| 模型 | 需预设K | 非球形 | 一句话 |
|---|---|---|---|
| K-means | 是 | 否 | 最简单高效，球形数据就选它 |
| 层次聚类 | 可后选 | 可以 | 树状图直观选 K，适合小数据 |
| DBSCAN | 否 | 是 | 自动发现聚类数，能识别噪声 |

> 决策：不确定分几类 → 层次聚类（树状图选 K）；数据量大且形状不规则 → DBSCAN；已知 K 且球形 → K-means。

## 四步解题流程
1. **标准化（必做）**：距离类算法（K-means/层次/DBSCAN）都基于距离，不标准化会被大数值特征绑架。用 z-score 或 min-max。
2. **定 K**：肘部法则（SSE-K 折线找拐点）+ 轮廓系数（取最大值的 K）。两者不一致以轮廓系数为准。看不出拐点 → 数据不适合 K-means，换层次/DBSCAN。
3. **聚类 + 可视化**：`n_init=10` 避免初值敏感；高维用 PCA 降到 2 维画散点（按簇着色）；雷达图展示每簇特征均值。
4. **结果解释（最关键）**：每个簇的特征均值/极值 → 给簇起"人设名"（如高价值 VIP / 流失风险）→ 给出差异化策略建议。只给标签不解释=白做。

## 常见坑（讲义 4.6）
- 忘标准化 → 结果完全不可用。
- 肘部法看不出拐点 → 换层次聚类或 DBSCAN。
- 聚类结果不解释 → 必须分析业务含义和策略。
- `n_init` 太小 → K-means 对初值敏感，设 10。
- 用准确率衡量聚类 → 无监督没有"正确答案"，用轮廓系数。
