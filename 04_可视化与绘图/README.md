# 04 可视化与绘图

> 依据讲义第 8.4/9.5/12.4 节。图是论文的"脸"：清晰、编号正确、图题在下方（图题在下方、表题在上方），能显著拉高"论文表达"维度分（占 20-25%）。

## 图表硬规范（无论 LaTeX 还是 Word）

1. **每张图必须有编号+图题**：图题写在图下方；表格题写在表上方；编号连续（图1、图2…）。
2. **清晰度 ≥150dpi**，格式 PNG/矢量图；**不要屏幕截图**贴论文。
3. **中文字体**：matplotlib 需设置 `SimHei`/`Microsoft YaHei`，否则中文变方块（本区模板已内置）。
4. 坐标轴要标单位、量纲；多线/多组要图例；配色全篇统一（如 tab10/viridis）。
5. 流程图/框架图（总体思路、算法流程、模型结构）用 draw.io / ProcessOn / TikZ 画，导入 PNG 或矢量。
6. 保存命名"见名知义"（如 `问题1_聚类散点.png`），按 `09_赛中工作区/图表素材` 集中管理。

## 国赛论文里"必备图"清单（来自六类模型套路）

| 场景 | 画什么图 |
|---|---|
| 数据初探 | 分布直方图、箱线图、相关性热力图 |
| 评价模型 | 权重柱状图、得分对比图、灵敏度前后排名对比 |
| 分类模型 | ROC 曲线对比、混淆矩阵、特征重要性 TopN |
| 聚类模型 | 肘部法则、轮廓系数、PCA 降维散点、每簇雷达图 |
| 预测模型 | 预测 vs 真实、未来预测+置信区间 |
| 优化模型 | 可行域/等高线(小规模)、GA 收敛曲线 |
| 机理模型 | 存量-流量系统框图、S(t)/I(t)/R(t) 曲线、参数敏感性曲线 |
| 全篇 | 总体建模流程图（放在"总体分析"章） |

## 文件清单

| 文件 | 用途 |
|---|---|
| `绘图代码模板.py` | 一键初始化中文字体 + 折线/柱状/散点/箱线/热力/雷达函数，改数据即用 |
| `绘图Prompt模板.md` | 让 AI 生成 matplotlib 代码的标准 Prompt + 最佳实践（讲义 12.4） |

## 使用建议

- 需要快速出图 → 直接改 `绘图代码模板.py`；
- 想让 AI 帮你写 → 用 `绘图Prompt模板.md` 里的 Prompt，生成后**逐行看过再跑**；
- 先出初版 → 运行看效果 → 迭代 2-3 轮 → 定稿，别指望一次到位（讲义 12.4）。
