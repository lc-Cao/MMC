# 绘图 Prompt 模板（AI 生成 matplotlib 代码）（讲义 12.4）

## 标准 Prompt（填空即用）

```
请用 matplotlib 画以下图：
- 类型：[散点图/折线图/柱状图/热力图/雷达图/箱线图/柱状堆叠图]
- 数据：[描述数据格式和范围，或直接粘贴小规模数据]
- X 轴：[标签，范围]
- Y 轴：[标签，范围]
- 图表要求：中文字体(SimHei)，分辨率150dpi，保存为PNG
- 配色方案：[tab10 / viridis / 自定义颜色，全篇统一]
- 特殊要求：[标注数据点 / 添加趋势线 / 添加图例位置 / 添加网格 / 显示数值]
```

## 最佳实践（讲义 12.4）

1. **迭代式生成**：先用 AI 生成初版 → 运行看效果 → 告诉 AI 哪里要改（"图例放右下、线粗一点、标题加单位"）→ 迭代 2-3 轮定稿。
2. `plt.savefig` 指定 `dpi=150`，文件名用中文（见名知义，如 `问题1_聚类散点.png`）。
3. AI 出的图你通常还要手动调：字体大小、标注位置、线宽——这是正常的。
4. 生成后**逐行审查再运行**；运行前确认数据没被 AI 改逻辑。
5. 中文乱码 → 检查 `plt.rcParams["font.sans-serif"]=["SimHei"]` 与 `axes.unicode_minus=False`；换字体试 `SimSun`/`Microsoft YaHei`。

## 论文图表自检（交图前 10 秒）

- [ ] 图题在下方、表题在上方，编号连续
- [ ] 坐标轴有标签+单位，图例齐全且不挡数据
- [ ] 清晰(150dpi+)，无乱码方块，颜色不是默认杂乱色
- [ ] 每个图的结论能在正文里对应一句"如图X所示，……"
