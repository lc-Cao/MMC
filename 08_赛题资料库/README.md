# 08 赛题资料库

> 用途：存放赛前下载的**历年真题、优秀论文、参考文献**，赛前精读、赛中随时查证。

## 子目录

| 目录 | 放什么 |
|---|---|
| `真题与优秀论文/` | 最近 3 年 A/B/C（本科）/D/E（专科）赛题 PDF 与官方/优秀获奖论文 |
| `参考文献/` | 赛中要引的文献（方法论、同类题方案），导出 GB/T 7714 或 BibTeX |

## 赛前动作清单（讲义 1.3 建议）

- [ ] 下载最近 3 年 A/B/C 题真题 + 优秀论文（竞赛官网/公众号/论坛）
- [ ] **至少精读 2 篇优秀论文**：重点看结构（摘要→问题重述→假设→总体分析→建模求解→检验→评价推广）与图表规范
- [ ] 观察近 3 年出题风格与热点方向（三年不重复但有周期、热点映射）
- [ ] 把要引的文献预存到 `参考文献/`，需要时直接复制引用条目
