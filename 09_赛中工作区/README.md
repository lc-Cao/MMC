# 09 赛中工作区（开赛后在这里干活）

> 这层是"脏区"：赛题附件、临时数据、模型试验代码、图表、论文工作副本都在这里折腾。
> **干净的模板/弹药库不要动**（`01`-`08` 只读），开赛时把要用的一份复制到本区。

## 子目录

| 目录 | 放什么 |
|---|---|
| `题目与附件/` | 官方下载的赛题 PDF、Excel/CSV 附件、图片 |
| `数据与代码/` | 清洗后的数据 + 各问的模型代码（从 `02_模型方法库` 复制模板来改） |
| `图表素材/` | 所有出图 PNG（≥150dpi），按问题编号命名，论文直接引用 |
| `论文工作副本/` | 从 `03_论文写作_LaTeX` 模板复制来的论文项目（LaTeX 主目录或 Word 文件），三人在这里协作 |
| `最终提交/` | 只放提交版 PDF 与附件，最后按 `07_合规与红线/提交前总检查清单.md` 走 |

## 开赛第一步（拿到题后 30 分钟内完成）

1. 把题目和附件放进 `题目与附件/`，立即云端备份；
2. 复制一份干净 LaTeX 模板到 `论文工作副本/`（重命名队号/题号）；
3. 在 `数据与代码/` 建 `q1/ q2/ q3/ q4/` 文件夹；
4. 新开 `每日对齐模板.md` 一份，按 2 小时碰头节奏记录。

## 文件命名规范（建议全队遵守）

```
代码：q1_topsis_v1.py（版本号递增，改一次存一次）
图  ：q1_权重对比.png、q2_预测vs真实.png（见名知义）
论文：论文-队号-初稿/终稿/提交版
```

## 每日进度记录（2 小时碰头时各说一句）

每 2 小时碰头 5 分钟：做了什么、遇到什么问题、接下来 2 小时做什么——记到 `每日对齐模板.md`，睡前合并成当天小结。
