# AI 提示词库（赛中直接复制）——讲义 12.2-12.5

> 使用纪律：先自己通读题目形成判断，再让 AI 辅助（避免被带偏）；同一道题可给两个 AI 交叉验证；AI 输出逐条审查。
> 绘图专用 Prompt 在 `04_可视化与绘图/绘图Prompt模板.md`。

## 1. 赛题分析 Prompt（定题前，每道候选题 10-15 分钟）

```
你是数学建模竞赛教练。请分析以下国赛题目并给出建议。

【粘贴题目全文】

请完成：
1. 用1句话概括每个小问的核心任务。
2. 每个小问列出2-3种可行方法，从简单到复杂排列，标注每种方法的适用条件和局限性。
3. 指出本题的3个关键难点，以及每个难点的应对思路。
4. 推荐一个整体建模框架（问题之间是什么关系？是否前一问的结果是后一问的输入？）。
5. 列出需要的数据类型和数据量级。如果附件没提供某个数据，给出替代方案。
6. 这道题对队伍有什么要求？（需要哪方面的知识储备？编程难度？）

要求：方法推荐以简单实用优先。复杂方法只在简单方法不够用时再考虑。
```

## 2. 定题后细化 Prompt（确定每问方法后，请 AI 展开推导与实现）

```
我们选定【题号】，初步方案是：
- 问题一用【方法A】
- 问题二用【方法B】
- 问题三用【方法C】

请针对这个方案：
1. 方法A的完整数学推导步骤是什么？给出核心公式和变量定义。
2. 方法A的 Python 实现需要哪些库？给出完整的代码框架（含函数定义、输入输出说明）。
3. 方法A可能遇到的3个问题及解决方案。
4. 问题一的结果如何作为问题二的输入？数据流转逻辑梳理清楚。
5. 整个方案的风险点在哪里？哪个环节最可能出问题？
```

## 3. 代码生成 Prompt 模板（让 AI"填空"，不让你从零写）

先自己设计函数接口（函数名、参数、返回值、处理步骤），再让 AI 填充实现：

```
请用 Python 实现以下函数。

函数名: entropy_topsis(data, benefit_cols)
输入:
- data: n×m 的 numpy ndarray，n=方案数，m=指标数
- benefit_cols: list，效益型指标（越大越好）的列索引

处理步骤:
1. 正向化：非效益型指标取其倒数，统一为"越大越好"
2. 标准化：min-max 标准化到[0,1]
3. 熵权法：计算每列的信息熵，信息熵越小权重越大
4. TOPSIS：构造加权标准化矩阵，计算每个方案到最优/最劣解的距离
5. 返回综合得分（相对贴近度）

输出:
- scores: 长度为n的1D array，每个方案的综合得分
- weights: 长度为m的1D array，每个指标的权重

要求:
- 仅依赖 numpy
- 每行代码加中文注释
- 给出一个简单示例验证正确性
- 考虑数值稳定性（除零保护）
```

**AI 代码三陷阱必查（讲义 12.3）**：
1. AI 会编造不存在的参数——不熟的参数去官方文档确认；
2. AI 会写逻辑对但效率极差的长循环——大数据量先测性能；
3. AI 会"不小心"改关键逻辑——只复制你要的改动，别整段替换。

## 4. 论文润色用法（讲义 12.5，绝不让 AI 整段代写）

先自己写完段落，再投给 AI：
```
请检查这段文字中的语法错误、术语不一致、表达不清的地方，逐一标注建议修改。
但不要改我的意思，不要添加我没有的信息。

【粘贴你自己的段落】
```
逐条审查建议：同意的改，不同意的保留原样。

## 5. 交叉验证（讲义 12.2 第 3 步）

- 把同一道题给**两个不同 AI 工具**分析，对比结论：一致 → 可靠；分歧 → 自己判断。
- 最终决定永远是你们三人做的，AI 只是参考。

## 6. 赛中红线（再次强调，讲义 12.6）

不用 AI 写摘要 / 不直接复制 AI 代码 / 不用 AI 查文献 / AI 内容占比≤30% / 一切 AI 结果必须验证。
