## 二、Python 环境准备（开赛前完成）

1. 安装依赖：`pip install -r requirements.txt`
2. 自检：运行 `python 环境自检.py`，**全部输出 OK** 才算通过。
3. 常见问题：
   - 库装不上 → 用 `python -m pip install --upgrade pip` 后再装；
   - 提示缺 C 编译器（少见，纯 Windows 库一般有 wheel）；
   - 中文画图乱码 → 确认系统有宋体/黑体，代码里 rcParams 已设置。

## 三、AI 在国赛中的定位（讲义 12.1）

| AI 擅长的（让它做，你审） | AI 不擅长的（必须你做） |
|---|---|
| 快速提取题目关键信息和数据要求 | 判断模型是否合理、假设是否恰当 |
| 生成 Python/LaTeX 代码框架 | 理解题目的深层含义和隐含约束 |
| 编写 matplotlib 绘图代码 | 解释"为什么选这个模型" |
| 批量数据清洗和转换代码 | 创新性的建模思路和方法组合 |
| 检查论文语法错误和格式 | 保证结果的正确性（AI 经常算错） |
| 中英翻译和文字润色 | **写摘要**（AI 写的摘要一眼假，直接扣分） |

> AI 是加速器，不是替代品。AI 生成的任何内容你都要逐行看过、能解释清楚——答辩时答不上来直接露馅（讲义 12 章前言）。

## 四、不可逾越的红线（讲义 12.6）

1. 不用 AI 写摘要。
2. 不直接复制 AI 代码——逐行看懂、本地跑通、假数据验证。
3. 不用 AI 查文献——AI 会编造不存在的论文和作者。
4. AI 生成内容占论文比例不超过 30%；核心建模思路和关键推导自己完成。
5. 所有 AI 生成结果（代码输出、图表数据）必须验证——AI 可以算错、用错公式。
