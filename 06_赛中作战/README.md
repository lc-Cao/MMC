# 06 赛中作战

> 依据讲义第 11 章。核心：**国赛输在时间管理上的队伍远比输在数学水平上的多。**
> 三天节奏踩对 + 三人并行不互等 = 成功一半。

## 本区文件

| 文件 | 用途 |
|---|---|
| `三天作战时间线.md` | 74 小时逐时段计划 + 每段"底线"，赛中随时对照 |
| `分工与协作.md` | 三人角色分工、T 型配合、最致命配合问题、协作机制 |
| `紧急预案.md` | 各类翻车场景的应急动作（打印一份放桌上） |

## 三条总原则（每 2 小时碰头时自问）

1. **不等队友**：三人永远在并行——建模手给方案、编程手立刻跑代码框架（假数据）、写手立刻写文字。
2. **先出结果再优化**：每个问先出"基线结果"，论文能交卷再回来升级。
3. **数据/代码/论文全程云端备份**，每 2 小时一次快照。

## 赛中节奏提醒

- 每 **2 小时碰头 5 分钟**：各说"做了什么、遇到什么问题、接下来 2 小时做什么"。
- 微信开免打扰，避免无意义刷屏；讨论集中到碰头时间。
- **22:00 前定题**；**提交提前 1 小时**（最后半小时网站必崩）。
- 每天睡前三人对齐明天的任务与底线。
