# 三天 74 小时作战时间线（讲义表 19 + 11.1）

> 打印一份贴墙上。**"底线"列是死任务，到了时间没完成就立刻切换策略（先简化、先出结果），不许恋战。**

## 第一天（18:00 开始）

| 时段 | 核心任务 | 底线 |
|---|---|---|
| 18:00-18:30 | 下载所有题目与附件；三人各自快速通读所有题，标注"能做/做不了/需查资料" | 不求深，先求全 |
| 18:30-20:00 | 每人深读 1-2 道候选，列"用什么方法/要什么数据/什么难点"→ 碰头 2 选 1 或 3 选 1 | 确定候选 |
| 20:00-22:00 | **定题** → 立刻查文献（知网/Scholar）；写手同步开写引言问题背景 | **22:00 前定题** |
| 22:00-01:00 | 第一问建模思路 + 代码框架（假数据跑通）+ 论文框架/目录 | **第一问思路必须出来** |

> 睡前三人对齐：明天上午做什么、中午前要出什么结果。

## 第二天（08:00 开始）

| 时段 | 核心任务 | 底线 |
|---|---|---|
| 08:00-12:00 | 攻克第一问：建模手完善公式，编程手真实数据求解+画图，写手写第一问论文段 | **中午前第一问出结果** |
| 13:00-18:00 | 攻克第二问（多数是第一问的延续，改代码即可）；写手先写框架留图表位置 | 不等模型，编程先跑 |
| 19:00-01:00 | 完善前两问：三人过一遍论文草稿，确保建模描述一致；有余力开始第三问思路 | **前两问必须完成** |

## 第三天（08:00 开始）

| 时段 | 核心任务 | 底线 |
|---|---|---|
| 08:00-12:00 | 攻克第三问（**最难的问题放上午头脑最清醒时**）；四问则上午第三、下午第四 | 有问就做，分问计分 |
| 13:00-18:00 | **灵敏度分析/误差分析/模型对比（必做，缺了直接降档）** + 全部收尾 + 补图 | 必做灵敏度 |
| 19:00-01:00 | 写手整合全篇、统一格式补图表编号；建模手查公式；编程手查数据准确性 | **所有求解完毕、初稿完整** |

## 第四天（提交日）

| 时段 | 核心任务 | 底线 |
|---|---|---|
| 08:00-12:00 | **早上第一件事：写摘要**（正文完成后写，确保数字一致）；三人分工通读论文（一人读模型、一人读结果、一人读格式），至少 3 遍 | 一早就写摘要 |
| 13:00-16:00 | 反复修改，重点字斟句酌摘要；格式检查（页码/字体/图表编号/参考文献） | 摘要数字都能在正文找到 |
| 16:00-19:00 | 最终排版 + 查重 + 导出 PDF，打开确认每页正常 | **留 1 小时 buffer** |
| **19:00 前** | **提交**（绝不拖到 20:00，最后半小时系统必崩）→ 下载确认文件完整 + 核对 MD5 | 提交=安全 |

> 记忆锚点：D1 晚定题 → D2 中午一问出结果 / 当晚前两问完成 → D3 做难题+灵敏度 / 当晚初稿 → D4 早写摘要 / 19:00 前提交。
