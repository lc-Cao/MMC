# 紧急预案（讲义 11.5）—— 打印贴桌上

| 翻车场景 | 立刻怎么做 |
|---|---|
| LaTeX 编译失败且救不回 | 切 Word 备用模板（赛前已设好格式，`03_论文写作_LaTeX/Word备用_格式速查.md`） |
| 代码跑不出结果 | 先出简化版本结果，论文写明"采用简化模型"，后面再优化 |
| 有人心态崩了 | 另两人立刻接手他的活——"先交卷再哭" |
| 电脑/网络坏了 | 代码+论文全程云端备份；备用手机热点；换机器开腾讯文档继续 |
| 题目太难做不动 | 查文献找简化版（同领域相近题目思路），先出结果再优化 |
| 模型卡在某问太久 | 放下这一问先做下一问（分问计分），回来再补 |
| 提交前网站崩了 | **提前 1 小时提交**；崩了就截图 + 联系组委会应急通道 |
| AI 生成代码跑不通 | 不硬调——把报错原文粘回 AI 让它修，或自己按逻辑重写关键段 |
| 突然发现某问结果错误 | 先评估影响：若只影响该问局部数字，改数字+摘要对应处；若影响全局结论，立即三人碰头决定 |
| 时间严重滞后（如 D2 晚前两问没完） | 砍目标：第三问用最简单模型出基线，优先保证"每问都有方法与结果" |

## 兜底三句

1. **有结果比完美重要 100 倍**——评委看的是你"做完全部问题"。
2. **提交了论文 ≥ 成功参赛奖**；没提交 = 0 分。
3. 前两问做不完不影响后两问——永远往前做。
