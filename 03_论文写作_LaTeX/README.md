## 怎么用「CUMCM论文模板_可编译」（jayxin/cumcm 版）

**模板结构**（主文档 = `main.tex`）：
```
CUMCM论文模板_可编译/
├─ commons/          样式：cumcmthesis.cls + cumcm2026.sty(AI声明) + preamble.tex(自定义宏包)
├─ contents/         内容都放这里
│  ├─ info.tex       论文基本信息（题号/队号/队员/指导教师）
│  ├─ abstract.tex   摘要 + 关键词
│  ├─ sections/s1~s6.tex   正文六个章节（现为模板示范，赛中替换为你的正文）
│  ├─ ai-usage.tex   AI 工具使用声明
│  ├─ references.tex 参考文献（按 GB/T 7714）
│  └─ appendix/a1~a3.tex   附录（放核心代码）
├─ figures/          论文图片
├─ fonts/            字体(7.5MB，随模板自带)
└─ docs/             官方文档：2026 格式规范修订稿、格式规范2019、通知等
```

**使用步骤**
1. 复制整个文件夹为比赛工作副本（放 `09_赛中工作区/论文工作副本`），保留本目录为干净模板；
2. 按顺序填：`contents/info.tex`（基本信息）→ `abstract.tex`（摘要，按 `摘要写作模板与自检.md` 写）→ 把 `s1~s6.tex` 逐个替换成你的论文章节（引言→模型建立与求解→模型检验→评价推广）；附录放核心代码；
3. 电子版提交去掉封面/编号页：`\documentclass[withoutpreface,bwprint]{commons/cumcmthesis}`（模板默认已是）；
4. **编译（XeLaTeX，需跑两遍）**：本机未装 TeX，推荐 Overleaf/TeXPage 上传本文件夹 → 编译器选 `XeLaTeX`、主文档设 `main.tex`、TeXLive 2023；
5. 模板源自开源项目 jayxin/cumcm（基于 latexstudio/CUMCMThesis 重构，MIT 许可），已含 2026 年 AI 工具使用声明与官方格式规范。

## LaTeX 5 步上手（讲义 8.2）

1. **复制模板**：把 CUMCM 模板整个文件夹复制，重命名为队伍编号/题号简称。**不要在原模板上改**，保留干净模板。
2. **改主文件**：只改三处——`\title{基于XX的XX}`、`\begin{abstract}...\end{abstract}`（按摘要模板写）、`\keywords{...}`。
3. **逐文件填充**：按编译引用顺序填写各章节 `.tex`（结构见下）。
4. **放图片和代码**：图片放 `figures/`，代码放 `code/`，用 `\includegraphics` 和 `\lstinputlisting` 引用。
5. **编译两次**（生成目录与交叉引用）：
   ```
   xelatex 论文-.tex
   xelatex 论文-.tex
   ```

## 模板文件结构与各文件填写指南（讲义 8.3）

```
制作模板-论文/
|-- 论文-.tex                主文件(编译入口)：标题+摘要+ \input 各章
|-- cumcmthesis.cls          文档类——绝不修改
|-- 1. 引言.tex              问题背景(1-2页)+问题重述(每个小问自己话概括)
|-- 2. 总体分析.tex          数据来源与特征 + 整体建模思路(必画总体流程图)
|-- 3. 模型假设.tex          5-8 条，每条带理由
|-- 4. 符号说明.tex          三线表：符号|含义|单位
|-- 5. 模型的建立与求解.tex  主章节，\input 子文件 5.1/5.2/5.3...
|-- 6. 模型检验.tex          灵敏度分析+误差分析+模型对比(国赛硬性要求!)
|-- 7. 模型评价.tex          优点(对应正文具体内容)+缺点(真实局限)
|-- 8. 模型改进推广.tex      2-3 条具体改进方向
|-- ref.bib                  BibTeX 参考文献库
|-- figures/  code/  fonts/
```

**每个小问的固定写法**（"具体分析→模型建立→模型求解"三节，讲义 8.3 第 6 节）：
- 求解部分必须含四要素：**输入数据是什么 → 用了什么方法 → 输出什么结果 → 结果说明什么**，缺一不完整。

## 写作纪律（贯穿全程）

1. **第一天晚上就开写**：写手先写引言/问题重述/总体分析，建模与写作同步推进（生存法则一）。
2. **摘要最后写**：正文完成后才写摘要，保证每个数字与方法名和正文完全一致（讲义 10.8）。
3. **每个问先出结果再优化**：论文永远有可写的"基线结果"。
4. 公式、图表编号统一交给 LaTeX 自动管理；图表缺编号=格式违规扣分。
5. 灵敏度/误差/模型对比不写 → 直接降档（讲义 1.4、6 章）。
