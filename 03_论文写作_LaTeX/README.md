## LaTeX 5 步上手（讲义 8.2）

1. **复制模板**：把 CUMCM 模板整个文件夹复制，重命名为队伍编号/题号简称。**不要在原模板上改**，保留干净模板。
2. **改主文件**：只改三处——`\title{基于XX的XX}`、`\begin{abstract}...\end{abstract}`（按摘要模板写）、`\keywords{...}`。
3. **逐文件填充**：按编译引用顺序填写各章节 `.tex`（结构见下）。
4. **放图片和代码**：图片放 `figures/`，代码放 `code/`，用 `\includegraphics` 和 `\lstinputlisting` 引用。
5. **编译两次**（生成目录与交叉引用）：
   ```
   xelatex 论文-.tex
   xelatex 论文-.tex
   ```

## 模板文件结构与各文件填写指南（讲义 8.3）

```
制作模板-论文/
|-- 论文-.tex                主文件(编译入口)：标题+摘要+ \input 各章
|-- cumcmthesis.cls          文档类——绝不修改
|-- 1. 引言.tex              问题背景(1-2页)+问题重述(每个小问自己话概括)
|-- 2. 总体分析.tex          数据来源与特征 + 整体建模思路(必画总体流程图)
|-- 3. 模型假设.tex          5-8 条，每条带理由
|-- 4. 符号说明.tex          三线表：符号|含义|单位
|-- 5. 模型的建立与求解.tex  主章节，\input 子文件 5.1/5.2/5.3...
|-- 6. 模型检验.tex          灵敏度分析+误差分析+模型对比(国赛硬性要求!)
|-- 7. 模型评价.tex          优点(对应正文具体内容)+缺点(真实局限)
|-- 8. 模型改进推广.tex      2-3 条具体改进方向
|-- ref.bib                  BibTeX 参考文献库
|-- figures/  code/  fonts/
```

**每个小问的固定写法**（"具体分析→模型建立→模型求解"三节，讲义 8.3 第 6 节）：
- 求解部分必须含四要素：**输入数据是什么 → 用了什么方法 → 输出什么结果 → 结果说明什么**，缺一不完整。

## 写作纪律（贯穿全程）

1. **第一天晚上就开写**：写手先写引言/问题重述/总体分析，建模与写作同步推进（生存法则一）。
2. **摘要最后写**：正文完成后才写摘要，保证每个数字与方法名和正文完全一致（讲义 10.8）。
3. **每个问先出结果再优化**：论文永远有可写的"基线结果"。
4. 公式、图表编号统一交给 LaTeX 自动管理；图表缺编号=格式违规扣分。
5. 灵敏度/误差/模型对比不写 → 直接降档（讲义 1.4、6 章）。
