# 参考文献：GB/T 7714 + BibTeX（讲义 8.6 / 13.2）

## 一、引用铁律

- **凡是别人的观点、数据、公式、图表，必须标注出处。不标 = 抄袭。**
- 必须引用：引用的数据、引用的公式（如"SIR 模型最早由 Kermack 和 McKendrick 提出[1]"）、参考的建模思路、引用的图片。
- 不需要引用：数学常识（线性回归公式、导数定义）、你自己推导的公式、自己画的数据图、自己写的代码。

## 二、GB/T 7714 格式（文中用方括号上标，文末按引用顺序排列）

```
期刊：[1] 张三, 李四. 基于XX的XX研究[J]. 某某学报, 2023, 45(3): 123-130.
书籍：[2] 王五. 数学建模方法[M]. 北京: 高等教育出版社, 2022.
网络：[3] 国家统计局. 2023年国民经济和社会发展统计公报[EB/OL]. http://xxx, 2024-02-29.
```

- 文中引用处写"文献[1]提出了……"；列表按正文引用顺序排，编号 [1][2][3]……
- 来源：知网搜索 → 勾选 → 导出/参考文献 → 选 GB/T 7714 → 复制。

## 三、LaTeX 模板中的用法（BibTeX）

1. 知网/Google Scholar 导出 **BibTeX** 格式，直接粘贴进 `ref.bib`，例如：

```bibtex
@article{zhang2023,
  author  = {张三 and 李四},
  title   = {基于XX的XX研究},
  journal = {某某学报},
  year    = {2023},
  volume  = {45},
  number  = {3},
  pages   = {123--130}
}
```

2. 正文引用：`如文献\cite{zhang2023}所述`；
3. 模板末尾会自动生成参考文献列表；
4. 需编译两次 `xelatex`（必要时加 `bibtex 论文-` 一步）让引用编号正确。

## 四、赛中防翻车

- **绝不用 AI 查文献**：AI 会编造不存在的论文与作者（讲义 12.6）。文献只去知网/万方/Google Scholar。
- 同一份数据/图表正文与摘要引用号要对齐；增删文献后要重新编译两遍。
- 全文重复率 >25% 直接取消评奖资格——**引言/背景最容易抄**，必须自己组织语言。
